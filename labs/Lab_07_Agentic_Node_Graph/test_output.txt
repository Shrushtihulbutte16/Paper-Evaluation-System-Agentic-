===== main.py =====

=== NODE GRAPH ===
requirement [requirement_agent] -> 
planner [planner_agent] -> 
builder [builder_agent] -> 
tester [tester_agent] -> 
reviewer [reviewer_agent] -> 
human_gate [human]

=== NODE CONTRACTS ===

Node: requirement
  Input: Campus event app goal
  Output: At least three clear app requirements
  Owner: requirement_agent
  Success criteria: See success predicate in code
  Retry behavior: Ask the user to clarify the goal, then retry once
  Failure behavior: escalate_to_human: goal is too vague
  Human approval: Not required

Node: planner
  Input: Extracted app requirements
  Output: A task mapped to every requirement
  Owner: planner_agent
  Success criteria: See success predicate in code
  Retry behavior: Regenerate the task breakdown once
  Failure behavior: return_to_requirement
  Human approval: Not required

Node: builder
  Input: Task breakdown
  Output: Generated application code and build status
  Owner: builder_agent
  Success criteria: See success predicate in code
  Retry behavior: Retry build once, then escalate to a human
  Failure behavior: retry_build_or_escalate
  Human approval: Not required

Node: tester
  Input: Generated application code
  Output: Automated test result
  Owner: tester_agent
  Success criteria: See success predicate in code
  Retry behavior: Send test failures to builder for correction
  Failure behavior: route_back_to_builder
  Human approval: Not required

Node: reviewer
  Input: Code and passing test result
  Output: Code-review status
  Owner: reviewer_agent
  Success criteria: See success predicate in code
  Retry behavior: Request fixes and run review again
  Failure behavior: route_back_to_builder
  Human approval: Not required

Node: human_gate
  Input: Reviewed application
  Output: Human sign-off
  Owner: human
  Success criteria: See success predicate in code
  Retry behavior: Revise according to human feedback
  Failure behavior: return_to_planner_with_human_feedback
  Human approval: Required before final acceptance
